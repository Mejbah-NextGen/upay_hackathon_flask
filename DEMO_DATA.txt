6. SAVINGS AND PAY LATER
------------------------------------------------------------------------
Savings: fixed monthly amount BDT 0.01–100,000; fixed tenure 1–120 months.
Demo annual simple return: 10%. Beginning-of-month contributions.
Principal = monthly amount × months.
Estimated return = monthly amount × 0.10 × months × (months + 1) / 24.
Example: BDT 100 monthly × 12 = BDT 1,200 principal + BDT 65 estimate.
Maximum 10 active saved goals per user; save/archive does not move wallet funds.
Savings records are estimates only. Compatibility startup seeds no savings plans.

9. INVOICES, QR, NOTIFICATIONS AND DISPLAY DEFAULTS
------------------------------------------------------------------------
Transaction reference: generated UPX... identifier; invoice: INV-{UPX reference}.
Bill invoice reference: normalized uppercase; unique per user/category/provider.
Browser submission tokens prevent repeated form payments; reads move no funds.
QR: signed demo instructions, expires after 15 minutes; does not execute payment.
Bill/cash QR is owner-only. Money request QR can be scanned by another wallet.
Notifications enabled by default; individual and mark-all read state persist.
Default language: English (en). Other option: বাংলা (bn).
Default theme: System. Other options: Light and Dark.
Assistant: local scoped guide without an API key; optional configured hosted AI.
Provider key, live balances and private user data are never exported here.
